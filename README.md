# ウポポ輪唱リズムゲーム

GitHub Pages公開用ファイルです。

## ファイル
- index.html
- chupka_wa_kamuy_ran.m4a

## GitHub Pages
1. GitHubで新しいRepositoryを作る
2. この2ファイルをRepositoryの一番上にアップロード
3. Settings → Pages
4. Sourceを「Deploy from a branch」
5. Branchを「main」、Folderを「/ (root)」にする
6. Save

数分後にGitHub PagesのURLでゲームを開けます。

## ゲームの流れ
スタート
→ 1（シネプ）
→ 2（トゥ）
→ 3（レ）
→ シノッチャケ アン ロー
→ 音源開始
→ プレイヤー1（音源）
→ 「チュプカーワー」でプレイヤー2開始
→ 「カームイラン」でプレイヤー3開始
→ 2拍子で点滅
→ 音源終了
→ 結果発表
→ もう一度
